Choose installed graphics for each network. Automatic matches package names. If a network’s package is unavailable to the game, it keeps the original ESPN graphics and logs the missing package; it does not relabel another network’s graphics.

WeekDate / kickoffMatchupCoverageNetwork

The schedule stores a 12-hour kickoff field without AM/PM. Sunday 9:30 is treated as a morning window; 7–11 otherwise means evening. This is an editable coverage model, not a verified TV listing. Equivalent copies of the same season schedule share overrides. New matchups receive automatic assignments; overrides never move or flex a game.
